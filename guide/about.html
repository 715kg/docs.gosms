О GoSMS API ​

GoSMS — это сервис для автоматизации отправки SMS через Android-смартфоны, подключённые к вашему аккаунту. Вы устанавливаете наше приложение на телефон, подключаете его к панели — и телефон становится вашим SMS-шлюзом.

GoSMS не является SMS-агрегатором и не берёт деньги за каждое сообщение. Вы платите за подписку на сервис, а сами SMS отправляются через SIM-карты ваших устройств по тарифу вашего мобильного оператора.

Что можно делать через API ​

Внешний API (/api/ext/v1/) позволяет интегрировать GoSMS в ваши приложения и автоматизации:

РазделЧто доступно
SMSОтправлять, просматривать историю, удалять записи
УстройстваПросматривать список, управлять настройками, удалять

Базовый URL ​

Все запросы отправляются на:

https://api.gosms.ru/api/ext/v1/

Формат данных ​

  • Тело запроса и ответа — JSON
  • Кодировка — UTF-8
  • Даты — формат ISO 8601: 2024-01-15T10:30:00Z

Ограничения ​

  • Максимальная длина SMS: 170 символов (независимо от алфавита — кириллица, латиница, эмодзи считаются одинаково)
  • Название устройства (своё): до 100 символов
  • Все запросы требуют авторизации по API-ключу
